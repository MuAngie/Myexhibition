# 永不消失的黑水城

静态展览网页。使用现场照片作为背景，按 `reference/main`、`1`、`B1`、`2`、`3` 分类浏览，不进行三维空间重建。

从父目录启动静态服务器，再打开 `/space5-heishui/`。也可以直接打开 `index.html`；返回展览体验馆和感受记录使用父目录中的 `shared/` 文件。

黑水城在展览墙目录中为第 05 个展览。旧入口 `/space-heishui/` 会跳转到新目录，并保留查询参数和展区编号。

功能：五个分区、63 张照片、3 段现场视频、原图缩放与拖动、键盘左右切换、纯空间观看、当前浏览器中的感受记录。视频在点击播放后才开始；MOV 原片保留下载入口。

`reference/` 保留原片。`assets/photos/` 和 `assets/thumbs/` 为纠正拍摄方向、按比例缩小后的 WebP 副本。若添加照片，可使用安装了 Pillow 的 Python 运行 `prepare-assets.py`，再在 `data.js` 中登记。照片标题用于导览，并非完整文物目录；准确内容请阅读展签原图。

页面不依赖远程字体、CDN 或构建工具。配色取自现场的暗部、沙土色展墙与暗红前言印记；字体沿用展览体验馆的宋体与系统中文字体。
