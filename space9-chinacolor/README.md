# 一瓷一色一世界 · 展览记录

以文件夹内72张现场照片制作的静态记录页。按红、蓝、黄、白、青、其他浏览，保留完整照片，不复原展厅空间。已加入项目首页浮光、展览墙及全部展览目录。

直接在浏览器打开本目录的 `index.html` 即可，无需安装前端依赖。也可以从项目根目录运行静态服务后访问 `/space9-chinacolor/index.html`。

## 浏览

- 六个分类分别收录12、15、11、7、17、10张照片；“全部”显示72张。
- 分类切换先展示该色的器物照片。每组可读现场展文，展览前言收在“其他”。
- 第65–69张现场照片分别作为红、蓝、黄、白、青的展示区背景，以低透明度、轻微虚化和边缘渐隐融入页面；背景跟随当前照片的釉色切换。“其他”保持浅色底。
- 缩略图、上一张/下一张和左右方向键切换照片。
- 点击大图查看原片，支持100%–500%缩放、滚轮缩放、放大后拖动、双击放大/复位、Esc关闭，以及单独打开原图。
- “我的感受”沿用共享 `exhibition-experience-feelings-v1` 存储，稳定ID为 `chinacolor`，只保存在当前浏览器。文件直开和不同HTTP地址的存储可能独立。

## 素材与来源

72张原始JPG全部保留在原位置，无覆盖、裁切或内容修饰。网页图应用EXIF方向并按比例缩小至长边2400px，缩略图长边360px。网页大图完整显示，缩略图为封面式显示。72张照片包括32张器物与展签、25张局部、5张篇章展文、1张前言、9张现场，不等于72件展品。

主视觉和展览资料来自[上海博物馆在上观发布的开幕报道](https://www.shobserver.com/sgh/detail?id=4026733)，原始海报和网页副本均保存在 `assets/` 中，页面打开后无外网图片请求。来源记录见 `assets/sources.json`。

五个篇章名称以现场展文为准，蓝釉为“碧落天工”，报道写作“碧落天宫”。“其他”为观看记录分组。照片标题为观看索引，正式器物名称、年代等以同框展签为准，未推测补写。

看展日期2026年10月10日来自照片EXIF；展期2026年7月18日至2027年2月14日、举办地点及50件展品的概述来自上述报道。

## 文件

- `index.html`、`styles.css`、`app.js`：页面和交互。
- `data.js`：分类、素材编号和观看索引。
- `prepare-assets.py`：生成网页图、缩略图和联系表，需要Pillow。
- `assets/manifest.json`：原片尺寸、拍摄时间与派生图路径。
- `analysis/photo-inventory.json`：72张照片的分组及素材角色。
- `analysis/contact-1.jpg` 至 `contact-3.jpg`：原片联系表。
- `analysis/desktop-preview.png`、`mobile-preview.png`：浏览器验收截图。
- `design-qa.md`：验收结果。
