# 将死亡带回生活 · 展览记录

以 `reference/` 中 17 张现场照片与 1 段现场视频构建的静态网页。保留展览内容与完整照片，以“理解死亡，也理解如何生活”为观看基调。网页导览分为序言、身体与痕迹、记忆的回声、回到生活四组，不代表原展官方章节或真实参观动线。

## 打开

直接在浏览器打开本目录的 `index.html`，无需安装前端依赖。也可以在项目根目录运行：

```powershell
python -m http.server 8088 --bind 127.0.0.1
```

然后浏览 `http://127.0.0.1:8088/space10-death/index.html`。从项目首页浮光、展览墙与全部展览目录也可进入。

## 浏览

- 通过四个导览分组、缩略图、上一项／下一项或左右方向键切换，全部素材按拍摄文件顺序保留。
- 点击照片查看原片，支持 100%–500% 缩放、滚轮缩放、放大后拖动、双击放大／复位及 Esc 关闭，也可单独打开原图。
- 前言、展签与问题墙可按阅读方式展开。作品名称、作者、年份和材料只采用能在现场照片中确认的信息。
- 现场视频由观众主动播放。原始 `IMG_5557.MOV` 容器时长约 2.62 秒，画面为 H.264（avc1），1920×1440，旋转 0°，音轨为 lpcm。已在 Chrome 156 中实测能解码并播放，其他浏览器兼容性未逐一确认。页面另保留原视频入口。
- “我的感受”沿用共享 `exhibition-experience-feelings-v1` 存储，以 `death` 为稳定 ID，只保存在当前浏览器。直接打开文件与不同 HTTP 地址的存储可能独立。
- 页末“延伸阅读”收录《相约星期二》《天蓝色的彼岸》《当呼吸化为空气》《最好的告别》《我与地坛》，附作者、内容简介、推荐理由及书籍介绍链接；顶部导航可直接跳转。书单来自本次看展后的阅读交流。

## 文件

- `index.html`、`styles.css`、`app.js`：页面、视觉与浏览交互。
- `data.js`：4 个导览分组与全部 18 项素材内容。
- `prepare-assets.py`：生成网页照片、缩略图、联系表与素材元数据，需要 Pillow。
- `assets/manifest.json`：照片原始尺寸、拍摄时间与派生图路径。
- `assets/video-metadata.json`：原始 MOV 容器与轨道元数据。
- `analysis/photo-inventory.json`：完整素材清单与来源说明。
- `analysis/contact-sheet.jpg`：17 张照片的联系表。
- `design-qa.md`：页面验收记录。

页面借用 `../shared/` 中的返回入口与感受存储，不引入第三方脚本、外部字体或网络图片。
