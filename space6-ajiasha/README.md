# 谜案，永不落幕

阿加莎·克里斯蒂主题展暨侦探小说珍藏展的静态照片网页。四个浏览章节、32 张展览照片和 4 张空间照片，分组与短标题用于照片导览，不是完整官方目录。

本展览是展览架目录中的第 6 项，目录名为 `space6-ajiasha`。从父目录启动静态服务器，打开 `/space6-ajiasha/`，也可直接打开 `index.html`。不需要安装前端依赖。返回展览体验馆和感受记录复用父目录 `shared/`；感受只保存在当前浏览器中。

旧路径 `/space-ajasha/` 只保留跳转页，自动转到新目录。展览 ID 与感受记录 ID 仍为 `ajasha`，不因目录更名而改变。

支持章节切换、缩略图选片、键盘左右翻页、完整照片查看、滚轮和按钮缩放、放大后拖动、四张空间背景切换。手机上可使用缩放按钮和单指拖动；按 Escape 退出放大或空间观看。

`reference/` 原片未修改。`assets/photos/` 和 `assets/thumbs/` 是已按 EXIF 纠正方向的 WebP 副本。运行 `prepare-assets.py` 可重新生成（需要 Pillow）。网页不依赖 CDN、远程字体或构建工具。
