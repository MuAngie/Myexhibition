# 虚与实 · 展览记录

基于 `reference/` 内 16 张现场照片制作的静态网页，参考项目的 `artwork-first-exhibition-gallery` skill。照片优先，不复原展厅几何与动线。首页浮光入口、展览墙和全部展览目录均已加入本场记录。

## 打开

直接用浏览器打开本目录的 `index.html`，或在项目根目录启动静态服务：

```powershell
python -m http.server 8088 --bind 127.0.0.1
```

浏览 `http://127.0.0.1:8088/space8-xushi/index.html`。页面不使用外部字体、第三方脚本或网络图片，无需安装前端依赖。

## 浏览

- 首页照片：IMG_5339，黄、蓝、紫三幅色域作品的组合照片。
- 页面固定背景：第 12 张 IMG_5344 展厅全景，叠加浅色半透明底层，以深色文字呈现；完整照片仍在浏览序列中。大图与感受面板也使用浅色背景。
- 全部照片按拍摄文件顺序浏览；四个分组用于编辑性导览，不代表真实展区或参观路线。
- 点击缩略图、上一张 / 下一张或左右方向键切换；序号显示当前分组内的位置。前后按钮位于照片上方的导航栏，滚动时吸附在顶部，按钮切图不主动调整页面滚动位置。
- “读前言”直接打开 IMG_5334，按阅读宽度展开，允许向下滚动。
- 点击主图打开原片大图，支持 100%–500% 缩放、滚轮缩放、放大后拖动、双击放大 / 复位以及 Esc 关闭。放大按钮适用于手机，另有“打开原图”入口。
- “我的感受”是整场展览的记录，沿用共享 `exhibition-experience-feelings-v1` 存储，以 `xushi` 为稳定 ID。只保存在当前浏览器；不同文件 / HTTP 地址的存储可能独立。

## 文件

- `index.html` / `styles.css` / `app.js`：页面、视觉与浏览交互。
- `data.js`：照片角色、分组、导览标题与说明。
- `prepare-assets.py`：处理 EXIF 方向，按比例生成长边最大 2400px 的网页照片及 320px 的缩略图，依赖 Pillow。
- `assets/manifest.json`：派生图、原始宽高与拍摄日期。
- `analysis/contact-sheet.jpg`：16 张原片联系表。
- `design-qa.md`：实际浏览器验收记录。

本页借用 `../shared/` 中已有的返回入口与感受存储，不修改其他展览的交互。
